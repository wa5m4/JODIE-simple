# 论文写作辅助 Skill

根据代码和实验结果辅助论文写作：

## 1. 方法描述 (Method Section)
- 根据 `models/` 和 `nas/` 代码生成方法描述
- 提取架构搜索空间（从 `search_space.py`）
- 描述训练流程（从 `training.py`）
- 生成伪代码或架构图建议

## 2. 实验部分 (Experiments)
- 基于实验配置生成实验设置描述
- 整理数据集统计信息
- 生成超参数表格
- 描述评估指标和基线

## 3. 相关工作 (Related Work)
- 结合 `/deep-research` 的结果
- 对比本工作与现有方法的区别
- 突出创新点

## 4. 结果展示
- 从实验日志生成结果描述
- 突出显著改进（用粗体/百分比）
- 生成消融实验分析

输出使用学术写作风格，避免口语化表达。
